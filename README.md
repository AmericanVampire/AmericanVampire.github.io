# Realm Guard Website

## Main structure
- `/` — Realm Guard application website
- `/servers/` — Server network selection
- `/servers/expendables-server/` — Expendables Server world/server selection
- `/servers/expendables-server/the-perfect-realm/home/` — The Perfect Realm home
- `/servers/expendables-server/skyblock/home/` — Skyblock starter portal
- `/servers/expendables-server/maze-runner/home/` — Maze Runner starter portal

The Perfect Realm pages now live entirely under:
`/servers/expendables-server/the-perfect-realm/`

Its shared assets/styles/scripts live under:
`/servers/expendables-server/the-perfect-realm/_site/`

The Realm Guard main site uses:
- `/css/main.css`
- `/js/main.js`
- `/assets/images/`
